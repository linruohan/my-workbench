# 发布标准

## 1. 版本号

SemVer `MAJOR.MINOR.PATCH`：

- `PATCH`：缺陷修复、文案 / 样式微调、工具描述修正，无数据与行为破坏。
- `MINOR`：新视图、新工具、新设置项、新材料化能力；快照 / 设置键可向后兼容。
- `MAJOR`：破坏性数据迁移、存储格式不兼容、平台要求提升。

当前版本 `0.1.13`。发版时同步以下位置：

1. `package.json` → `version`
2. `apps/desktop/package.json` → `version`
3. `apps/desktop/src-tauri/tauri.conf.json` → `version`
4. `apps/desktop/src-tauri/Cargo.toml` → `version`
5. `开发报告.md` 追加修订记录
6. `README.md` / `docs/design.md` 中的「当前版本」表述

## 2. 发版门禁

以下全部通过才可发版：

1. `npm run check` 通过（Prettier、Oxlint、四个包 `tsc`、全部 Vitest）。
2. `npm run build` 通过，无未处理警告。
3. `npm run pack:win` 成功，`nsis` 与 `msi` 产物存在。
4. 安装包在干净的 Windows 用户环境冷启动通过（删除 `%APPDATA%\my-workbench` 后首次启动）。
5. 旧版 `workbench.json` 能被读入并完成归一化，无字段丢失、无崩溃。
6. 新增 / 修改的 Agent 工具已同步 `docs/tools.md`；新增设置项已同步本文件与 `README.md`。
7. 无密钥、测试数据、临时脚本进入仓库或安装包。

## 3. 验收范围

### 3.1 任务与计划

- 今日 / 收件箱 / 已完成 / 项目切换正确；今日含逾期未完成，不含已删除父任务的孤儿子任务。
- 快速捕获：今天 / 明天 / 周五 / 下周X / M月D日 / 时刻 / 提前N分钟 / 截止 / #项目 全部命中。
- 列表、看板、统计三态可切换；看板拖拽改状态与项目桶。
- 子任务完成汇总到父任务；重复任务完成后推进到下一次；计时单实例、按日累加。
- 计划视图按日期时间线展示全部已排期任务。

### 3.2 定时任务

- 五种预设与自定义节奏的「下次运行」计算正确。
- 到期后创建 / 复用会话、绑定工作区与技能、写入通知。
- 应用关闭期间错过的触发不自动补跑；「立即执行」「跳过本次」行为正确。

### 3.3 知识库

- 可选择 / 切换 / 移除库根目录；重启后仍记住。
- Markdown 实时、源码、预览三态；编辑自动保存；磁盘内容一致。
- 文件树新建 / 重命名 / 删除 / 搜索 / 快速打开；Git 分支显示。
- 图片拖拽导入与预览；查找替换不破坏选区。

### 3.4 Agent

- 新建 / 归档 / 置顶会话；网页会话可打开与关闭。
- Provider 增删、模型拉取、连通性测试、代理、默认模型选择。
- 三档权限行为正确；破坏性操作始终确认；审批结果落库。
- 工作区工具：读 / 写 / 补丁 / glob / grep / shell / 终端 / 后台任务 / web / todo / 提问 / 子智能体 / goal / 定时 / 会话检索。
- 技能、记忆、命令、钩子、子智能体、插件、MCP 的启用与生效。
- 图片附件与本地 OCR 回退；语音输入在桌面端可用，模型缺失时提示。
- 上下文用量圆环、输入历史、消息队列、终端面板、工作区 rail 无错位。

### 3.5 提醒、通知、外观

- 15 秒内提醒触发，通知中心与提醒卡正确；冷却生效。
- 浅深主题切换、重启保留；系统字体扫描与界面字体生效。
- 系统通知开关当前不生效，发版说明中必须写明。

## 4. Release Notes

`npm run release:notes` 按提交分类生成草稿：新增功能、问题修复、改进优化、文档、其他。人工润色时：

- 面向用户写「能做什么」，不写内部文件名与 commit hash。
- 数据格式变化、快捷键变化、已知限制必须单列。
- 不承诺未落地能力（日历视图、FTS、系统通知、托盘、云同步等）。

## 5. 已知限制（发版必列）

- 提醒与定时任务依赖应用进程运行，退出后不触发。
- 系统通知开关未接线，仅有应用内通知。
- 知识库未建全文索引；跨库搜索以文件名与内容扫描为主。
- 业务数据主路径为 `workbench.db`（SQLite 增量持久化）；JSON 快照为兜底副本，最长 60 秒重写一次。
- 本地语音 / OCR 模型不随包，首次使用需联网下载。
- Office 转 PDF 依赖外部 libreoffice-kit，缺失时该工具不可用。
- 独立日历 / 时间表视图、标签导航页、第二设备同步未实现。

## 6. 回滚

1. 撤回 Release 与标签，重新上传上一版本安装包。
2. 若新版本已写坏快照：用发版前备份的 `%APPDATA%\my-workbench` 覆盖恢复；快照同时有 `localStorage` 备份。
3. 数据格式升级必须单独发版并在 Release Notes 标注「降级需恢复备份」。
4. 回滚后确认 `workbench.json` 可被旧版本读取；若不能，发布修复版并附恢复步骤。

## 7. 发布后

- 24 小时内确认 CI 全绿、Release 资产完整（Windows / Linux / macOS）。
- 记录首日崩溃、模型请求失败、语音 / OCR 下载失败反馈。
- 将需跟进问题写入 `开发报告.md` 或下一版计划，不留在聊天记录里。

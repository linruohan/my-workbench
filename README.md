# 个人工作台 (my-workbench)

本地优先的桌面个人工作台（Tauri 2 + React 19）。任务、定时任务、知识库、Agent、提醒与通知共用一套本机数据，不设云端账号，业务数据只落本机。

当前版本 `0.1.13`。

## 结构

```
apps/desktop     Tauri 2 + React 界面、Agent 运行时与原生能力
packages/domain  无 IO 的领域规则（任务 / 计划 / 重复 / Agent 契约 / 知识库路径 / 语音与 OCR 元数据）
packages/db      MemoryWorkbenchRepository（JSON 快照导入导出）与 SQLite 仓储实验
packages/theme   设计令牌与主题解析
```

## 功能列表

### 任务与计划

- **入口**：今日、收件箱、已完成、计划、项目、定时任务。
- **三种视图**：列表、看板、统计，随时切换。
- **列表**：按项目、标签、状态、今日与关键词筛选；支持子任务、预计时长与计时。
- **看板**：进行中 / 待办箱 / 已完成三列，可拖拽改状态与项目桶。
- **统计**：未完成、已逾期、今日到期、未排期、今日完成、完成率与项目分布。
- **任务字段**：计划日 / 具体时刻（互斥）、截止日期、提醒、重复、子任务、标签、预计时长、按日累计计时、任务备注。
- **今日规则**：只看未完成且计划日 ≤ 今天，逾期任务自动进入今日；今日支持手动排序。
- **快速捕获**：今天 / 明天 / 周五 / 下周X / M月D日、上午 / 下午 / HH:mm、`提前N分钟`、`截止…`、`#项目名`（项目不存在时自动创建）。
- **重复**：常用节奏与自定义周期，与定时任务共用节奏模型；任务完成后推进下一次。
- **项目**：收件箱 + 自建项目，项目内再分进行中 / 待办箱。
- **计划**：按日期时间线汇总全部已排期任务。

### 定时任务

- **节奏**：每小时、每天、工作日、每周、每月，或自定义「每 N 分 / 时 / 日 / 周 / 月 / 年」。
- **配置**：执行时刻、结束日期、启用开关、下次运行时间。
- **执行**：把指令或技能投递到 Agent；可复用已有会话或强制新建，并绑定工作区与技能。
- **控制**：立即执行、跳过本次；应用关闭期间错过的触发不会自动补跑。
- **通知**：每次触发写入通知中心，便于回看结果。

### 知识库

- **库管理**：选择多个本机目录作为知识库，切换当前库、记住最近库、移除库根。
- **文件类型**：Markdown、纯文本、代码 / 配置、常见图片。
- **文件树**：在当前目录新建 Markdown、重命名当前文件、移除库根、在资源管理器中显示、按名称筛选。
- **编辑**：实时预览（Typora 风格）、源码、纯预览三种模式；块级选择与操作。
- **效率**：查找替换、`Ctrl+P` 快速打开、命令面板按文件名 / 路径检索、Git 分支显示。
- **图片**：支持粘贴图片到笔记资源目录并在正文引用。
- **保存**：编辑后自动写盘，失败保留 dirty / error 状态。
- **兼容**：浏览器预览态只读；桌面端直接读写磁盘文件。
- **笔记**：应用内笔记与「最近笔记」入口。

### Agent

- **工作区**：内置默认工作区 + 按本机文件夹创建；会话按工作区组织，可置顶、归档。
- **会话形态**：普通对话与网页会话；网页会话在独立窗口打开。
- **模型 Provider**：内置免费模型通道、Ollama、OpenAI、DeepSeek、智谱、Anthropic Messages、自定义 OpenAI 兼容端点；支持拉取模型列表、连通性检查、默认模型与 HTTP 代理。
- **密钥**：Provider 配置与 API Key 保存在本机，仅随请求发送给对应 Provider。
- **权限**：变更前确认（默认）、本会话自动、只读三档；删除等破坏性操作始终需要确认，审批结果留有记录。
- **工作台工具**：任务 / 项目 / 标签 / 计时 / 笔记 / 搜索 / 通知 / 界面 / 设置 / 记忆 / 插件 / MCP。
- **工作区工具**：文件读写与补丁、`glob` / `grep`、`bash` / `pwsh` / `shell`、PTY 终端、后台任务、网页搜索与抓取、待办、向用户提问。
- **进阶工具**：子智能体、goal、定时任务、会话检索、`present`、Office 转 PDF、工作区依赖探测。
- **扩展**：技能、记忆、斜杠命令、钩子、子智能体、本地插件目录、MCP 服务器，统一在「设置 · Agent」管理。
- **钩子事件**：会话开始、任务完成、提醒触发。
- **图片与识图**：多模态图片附件；纯文本模型通道可回退到本地 PaddleOCR 识图，历史图片可再次读取。
- **语音输入**：SenseVoiceSmall / Fun-ASR-Nano-GGUF / QwenCTC 本地引擎，按住 CapsLock 说话；支持自动 / 中文 / 粤语 / 日语 / 韩语，焦点不在输入框时回退剪贴板粘贴。
- **输入体验**：斜杠命令、上下文用量圆环、输入历史、消息队列、终端面板。
- **长输出**：超长工具结果写入工作区 `.wb\spill\`，启动时清理 30 天前的文件。

### 提醒与通知

- **提醒选项**：不提醒、到点提醒、提前 5 / 10 / 15 / 30 / 60 分钟。
- **提醒类型**：计划提醒与截止提醒相互独立。
- **通知中心**：标题栏铃铛、到期提醒弹层、通知列表；支持「稍后」。
- **投递**：应用内每 15 秒扫描到期提醒与定时任务；同一次提醒被忽略后约 5 分钟冷却。
- **系统通知**：开关已保留偏好，但尚未接线，实际投递为应用内通知。

### 命令面板与快捷键

- `Ctrl+P` / `Ctrl+K`：跨任务、Agent 会话、应用内笔记、知识库文件、页面导航与项目检索，并可直接新建任务或笔记。
- `Ctrl+N`：聚焦当前视图的快速输入。
- `Esc`：关闭命令面板、菜单与弹层。
- Agent 输入框以 `/` 开头触发斜杠命令。

### 设置与外观

- **设置分组**：基础设置（常规、外观、通知、语音输入）、Agent（模型、个性化、记忆、子智能体、插件、MCP 服务器、技能、命令、钩子、工具）、数据与关于。
- **主题**：浅色 / 深色，重启保留。
- **字体**：扫描本机系统字体，分别设置界面字体与网页会话字体。
- **侧栏**：可折叠、可拖拽调宽，宽度持久化。
- **网络**：HTTP 代理仅作用于模型请求。

### 平台

- **桌面端**：文件读写、PTY 终端、语音、本地 OCR、网页窗口等能力仅在 Tauri 窗口可用。
- **浏览器预览**：可体验任务、计划、统计与部分 Agent 界面，但不能写本机知识库文件。
- **本地优先**：无云端账号；断网时任务、计划、知识库、提醒、通知与历史会话仍可用。

## 开发

环境要求：Node.js ≥ 20、Rust ≥ 1.90、Visual Studio Build Tools（C++ 桌面开发）、WebView2。首次使用本地语音或 OCR 需要联网下载模型，之后离线可用。

```bash
npm install
npm run check        # 格式 + lint + 类型 + 测试（发版门禁）
npm run dev          # Vite（浏览器预览，无原生能力）
npm run tauri:dev    # Tauri 原生窗口 + 前端 HMR
```

更多命令与约定见 [`docs/dev.md`](docs/dev.md)。

## 打包与发布

```bash
npm run pack:win     # 本机 Windows 桌面包
```

推送 `v*` 标签（或手动触发 Workflow）时，GitHub Actions 会先跑门禁，再构建 Windows / Linux / macOS（含 Apple Silicon）产物并上传 Release。详见 [`docs/packaging.md`](docs/packaging.md) 与 [`docs/release.md`](docs/release.md)。

## 数据

| 环境 | 位置 |
| --- | --- |
| Vite 预览 | 浏览器 `localStorage`（`wb.local.v1`） |
| Tauri 桌面 | `%APPDATA%\my-workbench` |
| 知识库正文 | 用户选择的本机目录（磁盘文件直读直写） |
| Provider / 密钥 | WebView `localStorage`（`wb.providers.v1`、`wb.credentials.v1`） |
| 本地模型 | `%APPDATA%\my-workbench\models\{paddleocr,sensevoice,funasr,qwenctc}` |
| Agent 溢出输出 | 工作区 `.wb\spill\` |

`workbench.json`（任务 / 项目 / 标签 / 笔记 / 定时任务 / Agent 会话快照）、`prefs.json`（设置）、`theme.json`（主题）都在桌面数据目录内，复制该目录即可完整备份。

断网时任务、计划、知识库、提醒、通知与历史 Agent 会话仍可用；仅调用外部模型、拉取远程模型目录或首次下载语音 / OCR 模型需要网络。
